# COMPUTER NETWORK (CAM5021C)

## UNIT-01: BASIC OF NETWORKS (28%)

- Basic Network
- Needs of Computer Networks
- History of Computer Network
- Networking Models
- Centralized & Decentralized
- Peer-to- Peer
- Client/Server
- Types of Computer Networks: LAN, MAN, WAN, PAN, SAN
- Network Topologies: Definition, Types of Topology, Advantages, Disadvantages
- Network Media & Devices: Hub, Switch, Repeater, Router, Bridge, Firewall, Gateway
- Transmission Media : Guided, Unguided

## UNIT-02: COMMUNICATION USING NETWORK (24%)

- Data Communication
- Signalling Techniques
- Principal Of data communication
- Data transferring techniques
- Introduction of IPv4
- Need of IP addressing
- Subnetting
- Network service
- Introduction of IPv6
- Configuration of IPv4 & IPv6
- Difference: IPv4 & IPv6
- Routing Protocols
- Algorithms

## UNIT-03: OSI & TCP/IP MODEL (18%)

- Introduction about OSI Model
- Understanding the Purpose and Function of Networking Models
- Layered Architecture
- OSI Layer and its Applications
- TCP/IP Model: Network Access Layer, Internet Layer, Host-to-Host Layer, Application Layer
- ASCII code

## UNIT-04: INTELLIGENT NETWORK SECURITY (30%)

- Introduction
- Definition & Objective: CIA triad, AAA, Threats & Vulnerabilities, Cryptography fundamentals, Common Attacks, Security Monitoring and Future Trends in Intelligent Network Security.
